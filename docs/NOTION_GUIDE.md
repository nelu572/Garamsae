# 가람새 Notion 기획서 안내서

> 기준 페이지: [가람새](https://app.notion.com/p/3d2b3e6e776c80888191c91d752f5b15?source=copy_link)
>
> 이 파일은 필요한 기획 문서를 바로 찾기 위한 색인이다. 세부 설정의 원본과 최신 상태는 Notion이며, 이 안내서만으로 세부 내용을 확정하지 않는다.

## 빠른 선택

| 필요 정보 | 먼저 볼 문서 | 범위 |
| --- | --- | --- |
| 게임의 핵심 콘셉트, 주인공, 이야기 출발점 | [가람새 개요](https://app.notion.com/p/3d2b3e6e776c801f8c67c14aa3d4e0cc) | 핵심 방향, 배경, 백이담, 스토리 시작, 세계의 핵심 비밀 |
| 국가·시대·지상/지하 구조·정치 설정 | [서광공화국 세계관](https://app.notion.com/p/3d2b3e6e776c80a98584d1323badf65b) | 세계와 대전쟁, 지상의 서광, 지하 핵심도시, 정보통제, 정치·비밀 권력, 다음 대전쟁, 미결정 설정 |
| 오프닝 흐름과 장면 연출 | [프롤로그](https://app.notion.com/p/3d2b3e6e776c8013a826fa6e6aadcf1d) | 장면 요약 및 장면별 상세 문서 |
| 등장인물의 소속·역할·개별 설정 | [캐릭터 DB](https://app.notion.com/p/3d2b3e6e776c80bd9380e1d033e19c94) | 이름, 계급 유형, 포지션과 인물별 페이지 |

```text
│  └─ 연출 · 설정 메모
└─ 캐릭터 DB
```

## 사용 규칙

1. 먼저 이 안내서에서 필요한 문서를 고른다.
2. 선택한 문서와 직접 연결된 하위 페이지만 읽는다.
3. 관련 없는 문서·하위 페이지는 탐색하지 않는다.
4. Notion의 변경·추가·삭제는 사용자가 명시적으로 요청한 경우에만 수행한다.
5. 이 색인은 Notion 구조가 달라졌거나 사용자가 갱신을 요청한 경우에만 다시 확인한다.
