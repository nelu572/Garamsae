## 사용 규칙

1. 먼저 이 안내서에서 필요한 문서를 고른다.
2. 선택한 문서와 직접 연결된 하위 페이지만 읽는다.
3. 관련 없는 문서·하위 페이지는 탐색하지 않는다.
4. Notion의 변경·추가·삭제는 사용자가 명시적으로 요청한 경우에만 수행한다.
5. 이 색인은 Notion 구조가 달라졌거나 사용자가 갱신을 요청한 경우에만 다시 확인한다.
6. 전체 탐색, 대규모 요약, 기획서 정리는 사용자가 명시적으로 요청한 경우에만 수행한다.
7. 구현 요청이 기획서와 충돌하거나 중요한 설계 선택이 필요하면 변경 전에 사용자에게 확인한다.
