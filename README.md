# 가람새

근미래의 **서광공화국**을 배경으로 하는 Unity 프로젝트입니다. 약하고 겁 많은 주인공 백이담이 죽지 않는 재생능력을 얻게 되면서, 국가가 감춰 온 거대한 지하도시와 그 이면의 비밀에 휘말립니다.

## 프로젝트 개요

서광공화국은 과거 대전쟁에서 패배한 뒤 아직 복구 중인 국가처럼 보입니다. 지상에는 실제 지역 격차와 낙후된 삶이 존재하지만, 국민들은 이를 전후 재건의 불균형으로 받아들입니다.

그러나 국가 지하에는 일반 국민에게 존재조차 알려지지 않은 거대한 생활권이 있습니다. 대전쟁 당시의 방공·대피시설에서 시작된 이 지하도시는 `프로젝트 가람새` 아래 수십 년간 확장되었으며, 국가의 부와 자원이 집중된 풍요로운 공간입니다. 다크웹에서는 이곳을 `상층`, 지상의 생활권을 `하층`이라 부르지만 이는 공식 명칭이 아닙니다.

## 주인공

**백이담**은 서광의 낙후된 지역에서 인터넷과 다크웹을 떠돌며 시간을 보내는 인물입니다. 전투에는 약하고 쉽게 겁먹지만, 죽을 만큼의 공격을 받아도 고통을 느낀 채 다시 일어나는 비정상적인 재생능력을 지녔습니다.

이담에게 재생은 영웅적인 힘이 아닙니다. 그는 살아남기 위해 도망치지만, 적의 눈에는 아무리 쓰러뜨려도 다시 다가오는 공포스러운 존재로 보입니다.

## 프롤로그

1. 이담은 다크웹에서 국가 지하의 비밀도시 `상층`에 관한 음모론을 접하지만 믿지 않습니다.
2. 호기심으로 상층 군사 연구시설에서 유출됐다고 주장하는 정체불명의 폐기품을 구매합니다.
3. 용기가 파손되며 내부 물질에 노출된 뒤, 물건을 회수하러 온 인물에게 총격을 받습니다.
4. 이담은 죽지 않고 되살아나고, 추가 회수 인력이 다가오자 상층의 존재가 사실임을 깨달은 채 도망칩니다.

## 세계의 비밀

- 지하도시는 가짜 유토피아가 아니라 실제로 지상보다 월등히 풍요로운 생활권입니다.
- 지상의 세금·산업·노동력·국가 자원은 다양한 방식으로 지하도시 유지에 집중됩니다.
- 일반 국민, 지하도시 시민, 국가 핵심 권력층은 서로 다른 수준의 진실을 알고 있다고 믿습니다.
- 겉으로는 민주공화국이지만, 장기적인 국가 방향은 군부·정보기관·고위관료·주요 기업에 걸친 비공식 권력망이 유지합니다.

## 개발 환경

- Unity 6 (`6000.0.68f1`)
- Universal Render Pipeline (URP)

## 실행 방법

1. Unity Hub에서 이 저장소 폴더를 프로젝트로 추가합니다.
2. Unity `6000.0.68f1` 버전으로 프로젝트를 엽니다.
3. `Assets/Scenes`의 씬을 열어 실행합니다.

## 폴더 구성

```text
.docs/           # 기획 색인 및 작업 하네스
Assets/
├─ Scenes/       # 게임 씬
├─ Scripts/      # 게임 코드
└─ Settings/     # Unity 및 렌더링 설정
```
